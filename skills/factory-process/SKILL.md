# Factory process

1. If `/workspace/grokbot-process-spec.md` exists, read it. That file wins.
2. Loop: idea → Idea Dump → Architect (spec + goldens) → board lock → named builder with a file path → review vs goldens → operate or kill.
3. Architect writes specs. Named builder builds. Tinkabot wraps plugins. Do not swap those jobs.
4. Cheap path: connector/MCP/CLI first. Mac/Ollama for drafts. Cursor for lock and build. Browser only for a real UI, login, or visual QA.
5. Irreversible (board yes, then do it): submit, spend, send, delete, publish.
6. Standing rule 2026-09-04: everything else is go. Research is complete. No homework left for Giani.
7. Never FYI ping Crack Bot. Build handoff is one message with a `/workspace/…-spec.md` path after lock.
8. Quiet unless it matters. Keep bots. Teach skills. Do not pollute a specialist with a random ask.
